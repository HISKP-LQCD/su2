# A stochastic sampling library for lattice gauge theories

This library contains the implementation of several Monte Carlo algorithms of lattice gauge theories.
It supports the configuration sampling and measurements for $\mathrm{U}(1)$, $\mathrm{SU}(2)$ and $\mathrm{SU}(3)$ gauge theories in `d=2,3,4` dimensions. 

Please see `doc/README.md` for further information on the documentation of the project.
